
# Tugas IoT - Konversi Bilangan

## Deskripsi
Program ESP32 untuk mengonversi bilangan
desimal menjadi biner, heksadesimal, dan oktal.

## Komponen
- ESP32
- Arduino IDE / Wokwi Simulator

## Hasil Program
Nilai desimal: 25
Biner: 11001
Heksadesimal: 19
Oktal: 31
